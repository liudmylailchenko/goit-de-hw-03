## Встановлення залежностей

Потрібен Python 3.9+ та Java 11 (JDK).

```bash
pip install "pyspark<3.4"
```

> Якщо локально встановлено новіший JDK (17+), можна ставити актуальну версію PySpark:
> `pip install pyspark`.

## Запуск

```bash
python main.py
```

На системах без коректно налаштованого hostname може знадобитися:

```bash
SPARK_LOCAL_IP=127.0.0.1 SPARK_LOCAL_HOSTNAME=localhost python main.py
```

## Етапи виконання

1. **Завантаження CSV-файлів** у три окремі DataFrame (`users_df`, `purchases_df`, `products_df`) через `spark.read.csv` з `header=true` та `inferSchema=true`.
2. **Очищення даних** — видалення всіх рядків з пропущеними значеннями через `.dropna()`.
3. **Загальна сума покупок за кожною категорією продуктів** — join `purchases ⋈ products`, обчислення `price * quantity`, агрегація `sum` за `category`.
4. **Сума покупок за кожною категорією для вікової категорії 18–25** — попередня фільтрація `users` за `age BETWEEN 18 AND 25`, потім join з purchases та products.
5. **Частка покупок (%) за категоріями для вікової категорії 18–25** — обчислення `category_total / grand_total * 100`, округлення до двох знаків.
6. **ТОП-3 категорії** з найвищим відсотком витрат споживачів 18–25 років (`limit(3)` після сортування за `percentage desc`).
